# Geometrical Space
## Controls :

### Camera mouvements :
- No camera mouvement possible

### Player actions (in levels) :
- Z, Left joystick up								= Fly foward

- Q, Left joystick left								= Fly left

- S, Left joystick right							= Fly right

- D, Left joystick down								= Fly backward

- Escape, Start, Select								= Pause/unpause the game (only in levels)

### Player actions (for UIs) :
- Mouse Left clic, Enter, South button gamepad		= Interact with buttons (UI)

- Z, Left joystick up								= Move up (UI)

- Q, Left joystick left								= Move left (UI)

- S, Left joystick right							= Move right (UI)

- D, Left joystick down								= Move down (UI)

## Context of the game's creation :
This game is a school project, we had to create a Bullet hell game in 2 weeks, all the documents who were created in the process are in [this folder](#f).
