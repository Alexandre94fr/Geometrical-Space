# Geometrical Space

## Context of the game's creation :
This game is a school project were we had to create a Bullet hell game in 2 weeks, all the documents who were created in the process are in [Documents](Documents).

## Controls :

### Camera mouvements :
- No camera mouvement possible

### Player actions (in levels) :
| Action                            | Input                                       |
|-----------------------------------|---------------------------------------------|
| Fly forward                       | Z, Left joystick up                         |
| Fly left                          | Q, Left joystick left                       |
| Fly right                         | S, Left joystick right                      |
| Fly backward                      | D, Left joystick down                       |
| Pause/unpause the game            | Escape, Start, Select                       |

### Player actions (for UIs) :
| Action                            | Input                                         |
|-----------------------------------|-----------------------------------------------|
| Interact with buttons             | Mouse left click, Enter, South button gamepad |
| Move up                           | Z, Left joystick up                           |
| Move left                         | Q, Left joystick left                         |
| Move right                        | S, Left joystick right                        |
| Move down                         | D, Left joystick down                         |
