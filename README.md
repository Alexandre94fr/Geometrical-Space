# Geometrical Space

## Context of the game's creation :
This game is a school project were we had to create a Bullet hell game in 2 weeks, I was the only student programmer for this project, all the documents who were created in the process are in the [Documents](Documents) folder.

## Controls :

### Camera mouvements :
- No camera mouvement possible

### Player actions (in levels) :

| Action                                                    | Input (AZERTY)                                                      | Input (QWERTY)                                                      |
|-----------------------------------------------------------|---------------------------------------------------------------------|---------------------------------------------------------------------|
| Fly upward                                                | Z, Left joystick up                                                 | W, Left joystick up                                                 |
| Fly left                                                  | Q, Left joystick left                                               | A, Left joystick left                                               |
| Fly backward                                              | S, Left joystick right                                              | S, Left joystick right                                              |
| Fly right                                                 | D, Left joystick down                                               | D, Left joystick down                                               |
| Pause/unpause the game                                    | Escape, Start, Select                                               | Escape, Start, Select                                               |

### Player actions (for UIs) :
| Action                                                    | Input (AZERTY)                                                      | Input (QWERTY)                                                      |
|-----------------------------------------------------------|---------------------------------------------------------------------|---------------------------------------------------------------------|
| Interact with buttons                                     | Mouse left click, Enter, South button gamepad                       | Mouse left click, Enter, South button gamepad                       |
| Move up                                                   | Z, Left joystick up                                                 | W, Left joystick up                                                 |
| Move left                                                 | Q, Left joystick left                                               | A, Left joystick left                                               |
| Move down                                                 | S, Left joystick right                                              | S, Left joystick right                                              |
| Move right                                                | D, Left joystick down                                               | D, Left joystick down                                               |
